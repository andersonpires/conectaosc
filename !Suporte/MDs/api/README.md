# API Structure

This folder is the new backend root for the REST API.

Current sprint status:
- Entry point: `api/public/index.php`
- API routes: `api/routes/api.php`
- MVC runtime classes are loaded from:
  - `api/core`
  - `api/controllers`
  - `api/services`
  - `api/repositories`
  - `api/models`
  - `api/middlewares`
